# 英语奇趣岛（中档版）— 6~8岁儿童多玩法英语学习

> 面向 6~8 岁儿童的英语学习 H5 小游戏，包含听音找图、词图配对、拼单词三种玩法，支持学习进度记录和错题复习。

## 项目简介

本项目是"儿童英语学习小游戏"实训的中档版本，在低档听音找图基础上增加了词图配对和拼单词玩法，并加入本地存储记录学习数据（最高分、错题本、学习报告）。

## 功能特性

### 三种玩法

| 玩法 | 说明 | 适合年龄 |
|------|------|---------|
| 🔊 听音找图 | 听发音，从图片中选出正确答案 | 3~8岁 |
| 🧩 词图配对 | 左边图片，右边单词，连线配对 | 6~8岁 |
| 🔤 拼单词 | 看图片听发音，按顺序点击字母拼出单词 | 6~8岁 |

### 题库规模
- **5 个主题**：动物、水果、颜色、食物、交通工具
- **每个主题 15 个单词**，合计 **75 个词汇**
- 颜色主题使用纯 CSS 颜色块，不使用 emoji

### 学习数据记录（本地存储）
- **最高分**：每个主题每种玩法的最高分自动保存
- **错题本**：答错的单词自动记录到错题本
- **错题复习**：首页和结算页提供错题复习入口，用听音找图模式复习错词
- **学习报告**：查看总完成轮数、总正确率、各主题正确率

### 游戏流程
1. **首页**：开始游戏 / 学习报告 / 错题复习
2. **玩法选择**：听音找图 / 词图配对 / 拼单词
3. **主题选择**：选择主题（显示单词数量）
4. **游戏进行**：答题、反馈、进度条
5. **结算页**：星星、正确率、错题复习入口、再玩一次
6. **学习报告**：数据统计 + 各主题正确率

### 交互设计
- **重播发音**：每题可重复播放发音
- **答错重试**：答错后可重新选择或重新拼写
- **拼单词取消**：点击已填字母槽可取消该位置及之后的字母，或点"清空重选"
- **词图配对**：先点图片再点单词，配对成功变绿发音，失败变红抖动
- **静音开关**：所有页面右上角静音按钮，状态保存到本地
- **手机触控**：大按钮、大图片，适配手指点击

## 技术方案

### 发音方案
使用**有道翻译 TTS 在线接口**播放英语发音：
- 接口：`https://dict.youdao.com/dictvoice?audio=单词&type=2`
- type=1 英式发音，type=2 美式发音
- 优点：不依赖浏览器语音合成，微信 / 安卓浏览器 / iOS 都能发音
- 备用方案：在线接口失败时回退到浏览器 Web Speech API

### 本地存储（localStorage）
所有学习数据保存在浏览器 localStorage 中：
- `ei_bestScore`：各主题各玩法最高分
- `ei_wrongWords`：错题本单词列表
- `ei_totalRounds`：总完成轮数
- `ei_totalCorrect`：总答对题数
- `ei_totalQuestions`：总答题数
- `ei_muted`：静音状态

关闭浏览器后重新打开，数据自动恢复。

### 答题防重复点击
- 使用 `locked` 变量防止一题内重复点击
- 使用 `timer` 变量管理 setTimeout
- 答错后高亮正确答案，自动进入下一题

## 各玩法规则

### 听音找图
- 每轮 10 题
- 每题 3 张图片（1 正确 + 2 干扰）
- 答对：变绿 + 鼓励语音 + 1秒后下一题
- 答错：变红 + 高亮正确答案 + 2秒后下一题

### 词图配对
- 每轮 5 组，每组 5 对，合计 25 题
- 先点左边图片，再点右边单词
- 配对成功：变绿 + 播放单词发音 + 禁用
- 配对失败：变红抖动 + 0.6秒后恢复

### 拼单词
- 每轮 10 题
- 看图片听发音，从打乱的字母中按顺序点击拼出单词
- 正确字母 + 2 个干扰字母
- 拼对：变绿 + 鼓励语音 + 下一题
- 拼错：变红 + 1.2秒后重置本题
- 可点击已填字母槽取消，或点"清空重选"

## 本地运行

### 方式一：直接打开
双击 `index.html` 即可在浏览器中运行。

### 方式二：本地服务器（推荐）
```bash
# 进入项目目录
cd english-island-mid

# 启动本地服务器（Python）
python -m http.server 8000

# 浏览器访问
# http://localhost:8000
```

### 手机测试
1. 电脑和手机连接同一 WiFi
2. 查看电脑 IP 地址（Windows：`ipconfig`）
3. 手机浏览器访问 `http://电脑IP:8000`

## 部署到 GitHub Pages

1. 在 GitHub 创建仓库 `english-island-mid`
2. 上传所有文件到仓库根目录
3. 仓库 Settings → Pages → Source 选择 `main` 分支 → Save
4. 访问 `https://你的用户名.github.io/english-island-mid/`
